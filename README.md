Developed an AI-powered assessment system that generates questions from
uploaded educational lessons using Retrieval-Augmented Generation.

**Key Features:** - Developed a Python backend using FastAPI. -
Implemented PDF upload and document processing using PyMuPDF. -
Generated text embeddings using all-MiniLM-L6-v2. - Integrated ChromaDB
for vector storage and semantic retrieval. - Implemented lesson-level

AI-powered question generation. - Developed subject-aware LLM routing
for Computer Science, Mathematics, and Physics. - Created REST APIs for
lesson uploads, quiz generation, and quiz submissions. - Implemented
assessment workflows connecting lessons, quizzes, student attempts, and
progress tracking. - Developed a Moodle plugin to integrate AI-generated
assessments into Moodle LMS.

**Technologies:** Python, FastAPI, MongoDB Atlas, ChromaDB, Groq API,
RAG, LLMs, PyMuPDF, Moodle.

### 2. Automated AQI Prediction System -- 72-Hour Forecast

**Gujrat, Pakistan \| 10Pearls Data Science Internship**

Developed an end-to-end machine learning system to forecast the Air
Quality Index (AQI) up to 72 hours ahead using historical air-quality
and weather data.

**Key Highlights:** - Engineered 29+ time-series features. - Trained and
evaluated Random Forest, XGBoost, and LightGBM models. - Achieved **R² =
0.82**, MAE = 11.65, and RMSE = 23.14 using Random Forest. - Automated
hourly data ingestion using GitHub Actions. - Implemented daily model
retraining and prediction workflows. - Used MongoDB Atlas for data
storage and GridFS for model management. - Applied SHAP for model
explainability. - Developed an interactive Streamlit dashboard for AQI
monitoring and forecasting.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, XGBoost,
LightGBM, MongoDB Atlas, SHAP, Streamlit, GitHub Actions.

**Live Demo:** [AQI Prediction
Dashboard](https://pearl-aqi-predictor.streamlit.app/)

### 3. NLP Sentiment Analysis System -- 5,600+ Tweets

Developed an NLP-based sentiment analysis system to extract and
visualize public sentiment from Twitter data.

**Key Highlights:** - Processed and analyzed 5,600+ tweets. - Performed
text preprocessing, tokenization, stopword removal, and lemmatization. -
Applied TextBlob for polarity and subjectivity analysis. - Classified
tweets into positive, neutral, and negative categories. - Visualized
sentiment distribution using charts and word clouds. - Developed
classification models using SVM, Naive Bayes, and Logistic Regression. -
Applied TF-IDF and Bag-of-Words for text representation. - Achieved an
F1-score of up to **0.77** across classification experiments.

**Sentiment Distribution:** - Positive: 44.1% - Neutral: 48.4% -
Negative: 7.4%

**Technologies:** Python, NLTK, TextBlob, Scikit-learn, TF-IDF, NLP,
Pandas, Matplotlib.
